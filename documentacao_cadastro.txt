1. VISAO GERAL
================================================================================

Tela de cadastro de novos usuarios (alunos ou motoristas). Possui dois modos:
- Cadastro de ALUNO (padrao): nome, CPF, email, telefone, senha, matricula,
  escola (combobox), endereco, cidade (combobox), data nascimento
- Cadastro de MOTORISTA: nome, CPF, email, telefone, senha, habilitacao,
  veiculo (combobox), cidade (combobox)

O usuario escolhe o tipo de perfil na aba "Entrar/Cadastrar" antes de preencher.

================================================================================
2. COMPONENTES DA INTERFACE
================================================================================

Header:

- Titulo "Criar Conta"

Abas de perfil (topo do formulario):

- "Cadastrar" -> mostra formulario de cadastro (ativo por padrao)

Dropdowns (Select):

Tabela: motorista
- id (BIGINT PK, auto-increment)
- nome (VARCHAR)
- cpf (VARCHAR) - unique
- email (VARCHAR) - unique
- telefone (VARCHAR)
- senha (VARCHAR) - bcrypt hash
- habilitacao (VARCHAR)
- veiculo (VARCHAR) - placa/descricao
- cidade_id (BIGINT FK -> cidade.id)

Tabela: cidade
- id (BIGINT PK, auto-increment)

Tabela: escola (pode nao existir no Java - verificado via mock)

Tabela: veiculo (pode nao existir no Java - verificado via mock)

================================================================================
5. VALIDACOES CLIENTE
================================================================================

Campo obrigatorio:
- Todos os campos sao obrigatorios (verificacao: campo.trim() === '')

CPF:
- Validacao via services/cpf.ts (validarCpf)
- Algoritmo de CPF: soma ponderada dos digitos verificadores
- Apenas digitos numericos sao aceitos
- Formatacao automatica: XXX.XXX.XXX-XX (formatarCpf)

Email:
- Deve conter '@' e '.'
- Validacao simples: email.includes('@') && email.includes('.')

Telefone:
- Apenas numeros: so digitos passam pelo onChangeText

Senha:
- Minimo 6 caracteres (validacao no formulario)
- Enviada em texto plano -> Java aplica bcrypt hash

Senha (confirmacao):
- Deve coincidir com campo "Senha"

Matricula (alunos):
- Campo texto livre

================================================================================
6. FLUXO DE NAVEGACAO
================================================================================

1. Usuario abre app -> cai na tela de login
2. Toca em "Criar conta" -> vai para /registo
3. Na aba "Cadastrar", escolhe "Aluno" ou "Motorista"
4. Preenche todos os campos obrigatorios
5. Toca "Cadastrar"
6. Em caso de sucesso:
   - Alert "Cadastro realizado com sucesso!"
   - Navega para /(auth)/ (tela de login)
7. Em caso de erro:
   - Alert com mensagem de erro (ex: "CPF ja cadastrado")
8. Link "Ja tenho conta?" -> navega para / (tela de login)
