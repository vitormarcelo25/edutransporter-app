Arquivo: app/avisos.tsx

================================================================================
1. VISAO GERAL
================================================================================

Centro de avisos/noticias do sistema. Exibe:
- Lista de avisos carregados da API
- Cards com icone, titulo, descricao e data
- Cores conforme tipo de aviso (urgente/info/ok)
- Pull-to-refresh para atualizar
- Notificacao para avisos urgentes
- Botao de teste de notificacao

================================================================================
2. COMPONENTES DA INTERFACE
================================================================================

Header:
- Botao voltar -> volta para tela anterior
- Titulo "Centro de Avisos"
- Botao de notificacao (sino) -> envia notificacao de teste

Loading:
- LoadingSpinner (60px)
- Texto: "Carregando avisos..."
- LoadingDots (animacao)

Lista de Avisos (ScrollView com pull-to-refresh):
- Card de aviso:
  * Borda lateral esquerda colorida (6px):
    - Vermelho (#EF4444): tipo "urgente"
    - Azul (#3182CE): tipo "info"
    - Verde (#48BB78): tipo "ok"
  * Icone no card (Ionicons):
    - urgente: icone vermelho com fundo transparente
    - info: icone azul com fundo transparente
    - ok: icone verde com fundo transparente
  * Titulo (16px bold)
  * Data (12px)
  * Descricao (14px, lineHeight 22)

Estado vazio:
- EmptyState com icone "bell-off"
- Titulo: "Nenhum aviso"
- Mensagem: "Quando houver novos avisos, voce vera aqui."
- Botao: "Atualizar"

Pull-to-refresh:
- RefreshControl com cor dourada (#F5A623)

================================================================================
3. CHAMADAS A API / SERVICOS
================================================================================

Servicos importados (services/api.ts):
- getAvisos()                     -> GET /api/avisos -> mock

Servicos de contexto:
- useApp() -> theme
- useToast() -> addToast (notificacoes in-app)
- useNotify() -> aviso (notificacao push local)

Detalhes:

  getAvisos()
  - GET /api/avisos  (Java backend)
  - Java: AvisoController.findAll()
    Query: SELECT * FROM aviso ORDER BY data DESC
  - Mock: retorna 2 avisos hardcoded:
    1. "Alteracao de Horario" - tipo: urgente
       Descricao: "Horario da rota ORE 3 alterado para 08:00"
       Data: "2025-01-15"
       Icon: alert-circle
    2. "Manutencao Programada" - tipo: info
       Descricao: "Onibus em manutencao, rota temporariamente suspensa"
       Data: "2025-01-14"
       Icon: tool
  - Retorna: { success: boolean, avisos?: Aviso[] }

  Notificacao push (useNotify):
  - sendAvisoNotification(titulo, descricao)
  - Envia notificacao local no dispositivo
  - Disparada automaticamente para avisos do tipo "urgente"

  Toast (useToast):
  - addToast('success', 'Avisos carregados!')
  - addToast('error', 'Erro ao carregar avisos')

================================================================================
4. TABELAS DO BANCO DE DADOS (MySQL via Java)
================================================================================

Tabela: aviso
- id (BIGINT PK, auto-increment)
- titulo (VARCHAR)
- descricao (TEXT)
- tipo (VARCHAR) - urgente / info / ok
- icon (VARCHAR) - nome do icone Ionicons
- data (DATE) - data de publicacao
- ativo (BOOLEAN, default true)
- created_at (TIMESTAMP)

================================================================================
5. VALIDACOES / REGRAS DE NEGOCIO
================================================================================

- Avisos urgentes disparam notificacao push automaticamente
- Pull-to-refresh recarrega lista completa
- Avisos ordenados por data (mais recente primeiro)
- Botao de teste de notificacao disponivel no header
- Toast de feedback: sucesso ao carregar, erro ao falhar
- Erro de conexao: lista fica vazia + toast de erro

================================================================================
6. FLUXO DE NAVEGACAO
================================================================================

1. Usuario clica em "Avisos" (Home) ou clica em aviso no feed -> /avisos
2. Tela carrega avisos via getAvisos()
3. Loading spinner exibido durante carregamento
4. Avisos aparecem em cards com cores conforme tipo
5. Avisos urgentes disparam notificacao push
6. Pull-to-refresh: usuario puxa para baixo -> recarrega
7. Botao de teste: envia notificacao de teste
8. Botao "Voltar" -> volta para tela anterior
