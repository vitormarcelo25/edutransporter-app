1. VISAO GERAL
================================================================================

Dashboard principal que exibe:
- Resumo do status da rota do dia
- Botoes de acao rapidos (paginas principais)
- Feed de avisos recentes
- Estatisticas (apenas para motorista)
- Saldo da carteira (placeholder para futuro)

O conteudo varia conforme o perfil do usuario (aluno vs motorista).

================================================================================
2. COMPONENTES DA INTERFACE
================================================================================

Header:
- Logo/titulo "EduTransporter"
- Botao de notificacoes (sino) -> abre painel de notificacoes
- Avatar do usuario com inicial do nome

Card de Rota do Dia:
- Nome da rota (ex: "ORE 3")
- Horario de partida
- Status: Agendada / Em Andamento / Encerrada
- Badge de status com cor (amarelo=agendada, verde=em andamento, cinza=encerrada)
- Botao "Ver no Mapa" -> navega para aba Mapa
- Botao "Iniciar Rota" (motorista) / "Confirmar Presenca" (aluno)

Botoes de Acao Rapida (grid):
- Mapa (icone map, verde)
- Agenda (icone calendar, roxo)
- Chat (icone message-circle, azul)
- Avisos (icone bell, amarelo)
- Perfil (icone user, azul escuro)
- Ajuda (icone help-circle, laranja)

Feed de Avisos:
- Lista dos 3 avisos mais recentes
- Card com icone, titulo, descricao e data
- Cor da borda lateral conforme tipo (vermelho=urgente, azul=info, verde=ok)
- Botao "Ver todos" -> navega para tela de Avisos

Estatisticas (apenas motorista):
- Total de alunos na rota
- Presentes hoje
- Ausentes hoje
- Confirmacoes pendentes

Carteira (placeholder):
- "Em breve" - funcionalidade de pagamento futura

================================================================================
3. CHAMADAS A API / SERVICOS
================================================================================

Servicos importados (services/api.ts):
- getRotaDoDia()                    -> GET /api/viagem/rota-do-dia -> mock
- getAvisos()                       -> GET /api/avisos             -> mock
- getPresencaResumo()               -> (usado internamente)
- getUserData()                     -> (via useApp context)

Detalhes:

  getRotaDoDia()
  - GET /api/viagem/rota-do-dia  (Java backend)
    Java: ViagemController.rotaDoDia()
    Query: SELECT * FROM viagem WHERE data = CURDATE() AND motorista_id = :id
  - Mock: retorna rota hardcoded com 5 alunos
  - Retorna: { success: boolean, rota?: Rota, message?: string }

  getAvisos()
  - GET /api/avisos  (Java backend)
  - Mock: retorna 2 avisos hardcoded:
    1. Aviso urgente "Alteracao de Horario" (tipo: urgente)
    2. Aviso info "Manutencao Programada" (tipo: info)
  - Retorna: { success: boolean, avisos?: Aviso[], message?: string }

  Contexto (useApp):
  - userRole: 'aluno' | 'motorista'
  - userData: { id, nome, cpf, ... }
  - isDark: boolean
  - theme: objeto com cores

================================================================================
4. TABELAS DO BANCO DE DADOS (MySQL via Java)
================================================================================

Tabela: viagem (rota do dia)
- id (BIGINT PK, auto-increment)
- nome (VARCHAR) - ex: "ORE 3"
- escola (VARCHAR)
- horario (VARCHAR) - ex: "07:30"
- tipo (VARCHAR) - ex: "Ida"
- data (DATE) - data da viagem
- status (VARCHAR) - agendada / em_andamento / encerrada
- motorista_id (BIGINT FK -> motorista.id)
- inicio_timestamp (TIMESTAMP) - quando a rota foi iniciada
- fim_timestamp (TIMESTAMP) - quando a rota foi encerrada

Tabela: presenca (status de presenca)
- id (BIGINT PK, auto-increment)
- aluno_id (BIGINT FK -> aluno.id)
- viagem_id (BIGINT FK -> viagem.id)
- presente (BOOLEAN)
- data (DATE)

Tabela: aviso (avisos/noticias)
- id (BIGINT PK, auto-increment)
- titulo (VARCHAR)
- descricao (TEXT)
- tipo (VARCHAR) - urgente / info / ok
- icon (VARCHAR) - nome do icone Feather
- data (DATE)
- ativo (BOOLEAN)

Tabela: aluno
- id, nome, cpf, email, telefone, senha, matricula, escola,
  endereco, data_nascimento, cidade_id, confirmou_presenca, viagem_id

Tabela: motorista
- id, nome, cpf, email, telefone, senha, habilitacao, veiculo, cidade_id

================================================================================
5. VALIDACOES / REGRAS DE NEGOCIO
================================================================================

- Rota so aparece se houver viagem agendada para o dia atual
- Motorista so ve estatisticas de presenca se a rota estiver "em_andamento"
- Aluno ve botao "Confirmar Presenca" apenas se a rota estiver ativa
- Avisos urgentes disparam notificacao push automaticamente
- Feed mostra no maximo 3 avisos recentes

================================================================================
6. FLUXO DE NAVEGACAO
================================================================================

1. Usuario loga -> cai na aba Home (inicio)
2. Toca "Ver no Mapa" -> navega para aba Mapa
3. Toca "Iniciar Rota" (motorista) -> navega para /iniciar-rota
4. Toca "Confirmar Presenca" (aluno) -> acao de confirmacao in-line
5. Toca botao de notificacoes -> abre painel de notificacoes
6. Toca em um aviso no feed -> navega para tela de Avisos
7. Toca "Ver todos" (avisos) -> navega para /avisos
8. Botoes de acao rapida -> navegam para as respectivas abas
