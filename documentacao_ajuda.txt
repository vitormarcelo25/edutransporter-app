1. VISAO GERAL
================================================================================

Central de ajuda com FAQ organizado por categorias. Funcionalidades:
- 5 categorias de ajuda com abas horizontais
- Perguntas em formato accordion (expandir/recolher)
- 21 perguntas e respostas pre-definidas
- Botao "Falar com o Suporte"
- Conteudo 100% estatico (sem chamadas a API)

CATEGORIAS (5):

3. presenca - "Presenca"
4. chat - "Chat & Avisos"

FAQ_DATA (21 perguntas):

conta (4):
1. "Esqueci minha senha, como redefino?" -> instrucoes de reset via email
2. "Como alternar entre perfil de Aluno e Motorista?" -> seletor na tela de login
3. "Como atualizar meus dados pessoais?" -> Perfil > Dados Pessoais
4. "Posso ter mais de uma conta no app?" -> Nao, apenas uma por CPF

rotas (5):
5. "O onibus nao aparece no mapa, o que fazer?" -> verificar internet e rota ativa
6. "Como sei qual e minha rota e horario?" -> aba Inicio e Agenda
7. "A rota foi alterada sem aviso. Como reclamar?" -> Chat com central
8. "Posso solicitacao mudanca de rota ou parada?" -> Perfil > Dados Pessoais
9. "O horario do onibus mudou, como fico sabendo?" -> avisos urgentes

presenca (3):
10. "Como confirmar minha presenca no onibus?" -> motorista marca ou app confirma
11. "O app marca que estou presente mas nao embarquei" -> Chat com central
12. "Meu filho faltou hoje. Preciso justificar?" -> 3 faltas consecutivas

chat (4):
13. "Como enviar uma mensagem pelo chat?" -> aba Chat
14. "Posso enviar fotos ou arquivos?" -> apenas texto, usar email
15. "Como silenciar notificacoes do chat?" -> Perfil > Notificacoes
16. "Recebi um aviso urgente, preciso fazer algo?" -> ler e seguir instrucoes

problemas (5):
17. "O app esta travando ou fechando sozinho" -> fechar, limpar cache, atualizar
18. "Nao recebo notificacoes push" -> verificar config do celular
19. "O mapa nao carrega a localizacao" -> ativar GPS e permissoes
20. "Como reportar um bug ou dar sugestao?" -> Chat ou email
21. "O app pede atualizar, sou obrigado?" -> recomendado manter atualizado

================================================================================
6. FLUXO DE NAVEGACAO
================================================================================

1. Usuario clica "Ajuda" (Perfil) -> navega para /ajuda
2. Tela carrega com categoria "Conta & Login" ativa
3. Usuario seleciona outra categoria -> lista de FAQs muda
4. Usuario clica em uma pergunta -> resposta expande com animacao
5. Usuario clica na mesma pergunta -> resposta recolhe
6. Usuario clica em "Falar com o Suporte" -> nada acontece (nao implementado)
7. Botao "Voltar" -> volta para tela anterior
