================================================================================
1. VISAO GERAL
================================================================================

Agenda de rotas futuras e passadas. Exibe:
- Calendario visual com dias que possuem rotas (marcadores amarelos)
- Lista de rotas para o dia selecionado
- Status de cada rota (agendada, concluida, cancelada)
- Navegacao por meses

================================================================================
2. COMPONENTES DA INTERFACE
================================================================================

Header:
- Botao voltar -> volta para home
- Titulo "Agenda"
- Navegacao de mes: "< Mês Ano >"

Calendario:
- Grid 7 colunas (Dom a Sex/Sab)
- Dias com rotas: marcador amarelo (ponto)
- Dia selecionado: fundo dourado (#F5A623)
- Dia atual: borda dourada
- Dias sem rota: sem marcador
- Dias passados com rotas: marcador cinza

Lista de Rotas (abaixo do calendario):
- Card com borda lateral colorida:
  * Verde (#48BB78): rota concluida
  * Amarelo (#F5A623): rota agendada
  * Vermelho (#EF4444): rota cancelada
- Conteudo do card:
  * Nome da rota (ex: "ORE 3")
  * Horario (ex: "07:30 - 11:00")
  * Escola (ex: "Escola Municipal ABC")
  * Tipo (ex: "Ida" / "Volta")
  * Badge de status

Mensagem de vazio:
- "Nenhuma rota para este dia"
- "Nenhuma rota encontrada"

================================================================================
3. CHAMADAS A API / SERVICOS
================================================================================

Servicos importados (services/api.ts):
- getRotasDoMes(ano, mes)     -> GET /api/viagem/mes/:ano/:mes -> mock
- getRotasDoDia(data)         -> GET /api/viagem/dia/:data     -> mock

Detalhes:

  getRotasDoMes(ano, mes)
  - GET /api/viagem/mes/{ano}/{mes}  (Java backend)
  - Java: ViagemController.findByMes()
  - Query: SELECT * FROM viagem WHERE MONTH(data) = :mes AND YEAR(data) = :ano
  - Mock: retorna 2 rotas hardcoded:
    1. "ORE 3" - 07:30 - Escola ABC - agendada
    2. "ORE 5" - 14:00 - Escola XYZ - concluida
  - Retorna: { success: boolean, rotas?: Rota[] }

  getRotasDoDia(data)
  - GET /api/viagem/dia/{data}  (Java backend)
  - Java: ViagemController.findByData()
  - Query: SELECT * FROM viagem WHERE data = :data
  - Mock: retorna rotas do dia especificado
  - Retorna: { success: boolean, rotas?: Rota[] }

================================================================================
4. TABELAS DO BANCO DE DADOS (MySQL via Java)
================================================================================

Tabela: viagem
- id (BIGINT PK, auto-increment)
- nome (VARCHAR) - ex: "ORE 3"
- escola (VARCHAR)
- horario (VARCHAR) - ex: "07:30"
- tipo (VARCHAR) - ex: "Ida" / "Volta"
- data (DATE) - data da viagem
- status (VARCHAR) - agendada / concluida / cancelada / em_andamento
- motorista_id (BIGINT FK -> motorista.id)
- inicio_timestamp (TIMESTAMP)
- fim_timestamp (TIMESTAMP)

Tabela: feriado (futuro)
- id (BIGINT PK, auto-increment)
- data (DATE) - unique
- nome (VARCHAR) - ex: "Natal"
- descricao (VARCHAR)

================================================================================
5. VALIDACOES / REGRAS DE NEGOCIO
================================================================================

- Calendario inicia no mes atual
- Apenas dias com rotas sao clicaveis (marcador amarelo)
- Dias futuros podem ter rotas agendadas
- Dias passados mostram rotas concluidas ou canceladas
- Status da rota determina cor do card
- Click em dia selecionado recarrega lista de rotas
- Navegacao por mes: seta esquerda/direita

================================================================================
6. FLUXO DE NAVEGACAO
================================================================================

1. Usuario clica em "Agenda" (Home) -> navega para aba Calendario
2. Calendario carrega mes atual e busca rotas
3. Dias com rotas aparecem com marcador amarelo
4. Usuario clica em um dia -> lista de rotas daquele dia aparece
5. Usuario navega entre meses com as setas
6. Botao "Voltar" -> volta para Home
